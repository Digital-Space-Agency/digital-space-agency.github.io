FlutterFix

Open-source tool that lets testers long-press a bug in a Flutter app, then sends the report to Claude, which opens a pull request with the fix. MIT licensed.

You spot a bug on your phone, nowhere near a computer. Writing it up takes longer than fixing it, so you forget. FlutterFix removes the write-up and the computer: long-press the broken thing and Claude opens a pull request.

What it is

FlutterFix is an open-source, MIT-licensed tool for Flutter teams. A tester long-presses a bug in a running Flutter app, the report goes to Claude, and Claude opens a pull request with the fix.

github.com/digital-space-agency-com/flutterfix

My role

I created and maintain FlutterFix.

What I built

  • Created and maintain FlutterFix, an open-source MIT-licensed Dart package, widget, receiver and server for Flutter teams.
  • A tester long-presses the element, types one sentence, and the report is sent with the element, its text, the widget path that built it, a screenshot with the element outlined and a replay of the seconds before.

Architecture and approach

  • A Flutter widget that resolves the pressed element, outlines it and captures a screenshot and a replay of the preceding seconds.
  • Two sinks behind one interface: LocalReceiverSink for use at the desk, straight into a running Claude Code session; HttpSink plus OutboxSink for use anywhere.
  • The cloud route: a Firebase function checks sign-in and a tester list, applies a daily cap and creates a GitHub issue with the screenshot; a GitHub Action then runs Claude, which opens a pull request.
  • Nothing is merged automatically; your usual checks run on the pull request and you review it in the GitHub mobile app.

Hard problems

Context that makes a fix possible

A screenshot alone is not enough. Attaching the element, its text and the widget chain gives Claude enough context to find the code.

Flaky and slow screens

Replay captures the seconds before the press, so empty lists, slow loads and animation glitches are visible in the report.

Safe by default

Reports are limited to signed-in testers, capped per day and never merge themselves.

Outcome

  • Open source on GitHub under the MIT licence.
  • Works at your Mac in about five minutes, or away from it in about an hour of one-off setup.
